## 一个例子，让你明白分阶段有多重要

🔬 在平台里搜"白蛋白"，你会拿到 **10 条**：

```
实验室检查表 | 入院前        | albumin   ← 术前营养状态
实验室检查表 | 入院到手术开始 | albumin   ← 离手术最近的术前值
实验室检查表 | 手术期间       | albumin   ← 被手术打击后的值，不能当基线
实验室检查表 | 手术结束到出院 | albumin   ← 术后恢复情况
术中生命体征表 | 入院到手术开始 | alb5 / alb20   ← 输注量，不是化验值
术中生命体征表 | 手术期间      | alb5 / alb20
术中生命体征表 | 手术结束到出院 | alb5 / alb20
```

**它们是 10 个不同的变量。** 勾错一条，"术前白蛋白"就变成了"术后白蛋白"。

同一次住院里，白蛋白可能测了七八次。分阶段解决"大概在哪一段"，时间窗解决"段里取哪一次"：

```
时间窗 = 阶段终点往前 t 分钟
t = 1440  →  术前 24 小时
t = 10080 →  术前 7 天
```

---

## 三句话记住核心

1. **同一个变量有五份**，因为要分五个阶段（入院前 → 入院到手术开始 → 手术期间 → 手术结束到出院 → 出院后）分别取。
2. **时间窗 = 阶段终点往前 t 分钟**，t 用 1440 表示 24 小时；术前指标用"末次"，术中指标用"均值"。
3. **暴露只能取一个阶段，协变量取暴露及之前，结局可以取任意阶段**——平台用阶段先后顺序堵住了因果倒置。

## 教程特色

- 🔬 **全部数据实测**：带 🔬 标记的数字都来自对平台的真实操作与对导出字段的逐列核对，不是估计值
- 🎯 **讲清楚"为什么"**：每个操作都交代背后的道理，而不是让你照着点
- 🕳️ **踩坑清单**：第十二章汇总了实测踩过的坑，附"症状 → 原因 → 解决"
- 📋 **自检清单**：选变量、设时间窗、下载后核对，都有 checklist
- 💻 **可复现代码**：完整的 R 分析代码 + 论文方法学段落模板
